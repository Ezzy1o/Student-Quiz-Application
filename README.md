# 🇲🇾 Malaysia General Knowledge Quiz

A simple Android quiz application developed using **Kotlin** in **Android Studio**.

The application allows users to enter their name, answer 5 Malaysia General Knowledge questions, navigate between questions using Previous and Next buttons, and view their final score.

This project was developed as part of our Android application assignment.

## 📱 Application Features

- Student name input
- Malaysia General Knowledge quiz
- 5 multiple-choice questions
- One question displayed at a time
- Previous and Next navigation
- Progress indicator
- Selected answers are saved when navigating between questions
- Automatic score calculation
- Result screen
- Try Again function
- Activity Lifecycle logging using Logcat
